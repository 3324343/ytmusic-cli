a simple useless youtube music terminal player

![](images.png)

## 📚 Installation

Debian/Ubuntu
```
sudo apt upgrade
apt install python mpv git
pip install yt-dlp rich
git clone https://github.com/3324343/ytmusic-cli
```
Arch Linux
```
sudo pacman -Syu
sudo pacman -S python mpv yt-dlp git
git clone https://github.com/3324343/ytmusic-cli
```
